# oi-keiba-3d-demo

南関東競馬（大井・川崎）予想シミュレーション 3Dデモ。`index.html` のみで動作する静的サイト（依存ゼロ）。Render の Static Site で公開。

- `index.html` … 予想シミュレーション＋3D。`?track=oi` / `?track=kawasaki`
- `race.html` … 出馬表（競馬新聞の馬柱レイアウト。3Dなし・スマホ対応）
- `data.html` … データブラウザ（騎手・調教師・厩舎×騎手・馬主・種牡馬・母の父・場/距離の傾向・成績/回収率・指数の読み方）
- `boat.html` … ボートレース版
- `data/nankan/` … 騎手・調教師・コンビ・馬主の指数データベースと、生成した番組・出走馬
- `tools/` … nankankeiba.com からの取り込みと、index.html へのデータ埋め込み

データの更新手順・指数の定義・守るべき要件は [CLAUDE.md](CLAUDE.md) を参照。

## いまのモデルの実力

物理シミュレータのほかに、条件付きロジット（Plackett–Luce）を2段構成で作って比較している。
2026-06〜09 の537レース（学習は2025-09〜2026-05の2,413レース）で検証した結果：

- ロジット第1段は**シミュレータより明確に良い**（上位3頭に勝ち馬 55% → 64.8%）
- ただし**単勝人気と合成しても人気を超えない**（第2段の係数は 基礎0.204／人気0.707）
- **どの券種・BOXサイズでも回収率100%に届かない**（控除率20〜25%を超えられていない）

つまり順位付けの精度は上がったが、**馬券の判断には使えない**。詳細は data.html の「成績・回収率」タブ。
